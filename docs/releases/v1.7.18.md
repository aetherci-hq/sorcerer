# Sorcerer v1.7.18

Released: 2026-04-28

## Highlights

- Restores panel layouts across restart, including split-pane state, active panel targets, and detached pop-out windows.
- Adds independent split layouts inside pop-out windows so detached workspaces can be expanded without mutating the main window.
- Hardens Codex session capture, resume, and import behavior to better support multiple sessions in the same working directory.

## Fixes and polish

- Reduces noisy Codex state DB warnings when the newest local snapshot is temporarily unreadable.
- Improves import-session UX with clearer provider filtering, explicit created/updated metadata, and better card layout.
- Fixes pane relocation so moving a loaded session between split panels clears the source panel correctly.
- Shows Claude provider badges consistently in the sidebar and refreshes sticky Codex capture and resume warning state.

## Notes

- This release includes all commits since `v1.7.17`.
- GitHub Actions release packaging is triggered by pushing the `v1.7.18` tag.
