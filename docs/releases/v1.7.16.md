# Sorcerer v1.7.16

Released: 2026-04-19

## Highlights

- Hardens session resume matching for Codex by reconciling local state with CLI sessions and surfacing session diagnostics directly in the UI.
- Adds external session import for Codex and Claude Code so sessions started outside Sorcerer can be discovered and attached to a project.
- Improves resume feedback with visible loading states and tighter menu behavior around imported and resumable sessions.

## Fixes and polish

- Detects useful Claude conversation titles from transcript content instead of leaving imported sessions unnamed.
- Filters and presents import candidates more cleanly so already-known sessions are not re-imported.
- Refines resume-state labels, session info styling, terminal theme consistency, and split-panel active-state visuals.
- Keeps session context menus fully within the viewport, including menus that change size after async diagnostics load.

## Notes

- This release includes all commits since `v1.7.15`.
- GitHub Actions release packaging is triggered by pushing the `v1.7.16` tag.
