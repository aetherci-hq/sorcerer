# Sorcerer v1.7.20

Released: 2026-05-02

## Highlights

- Delivers a major sidebar refinement pass with flatter hierarchy, stronger grouping, cleaner metadata layout, and more consistent drag-and-drop behavior across projects and agents.
- Expands and hardens the theme system, including monochrome dark and broader token cleanup so renderer surfaces rely less on hardcoded colors.
- Improves release readiness with startup/shutdown lifecycle hardening, lower sidebar/pop-out churn, and safer settings/feedback flows.

## Fixes and polish

- Fixes project/group drag behavior regressions and keeps collapsed and expanded sidebar ordering consistent.
- Restores rounded active selection styling while keeping the newer sidebar structure and metadata layout improvements.
- Adds an in-app feedback flow with an optional sidebar footer button and a General setting to hide it.
- Replaces misleading settings browse actions with proper file/directory picking, makes the worktree path display truthful, and improves settings accessibility for toggle controls.
- Clears stale feedback drafts on close, pre-fills feedback contact details from profile settings, and fixes avatar fallback so removed profile images do not linger.
- Persists normal PTY exits back to idle state, debounces window-bounds writes, and waits for Codex exit metadata persistence during shutdown.
- Prevents startup/shutdown lifecycle work from stacking or leaking across window reopen cycles, and reduces pop-out/session sidebar timer churn.

## Notes

- This release includes all commits currently ahead of `origin/main`.
- GitHub Actions release packaging is triggered by pushing the `v1.7.20` tag.
