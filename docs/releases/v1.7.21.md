# Sorcerer v1.7.21

Released: 2026-05-04

## Highlights

- Fixes the split-panel header rendering bug where the right-side controls could appear to pick up an incorrect translucent background after creating a split.
- Hardens split panel composition by isolating header chrome from panel content, which keeps focus styling stable as panels are split and terminals are reattached.
- Resolves the Popout Fast Refresh warning in development by separating non-component popout detection from the `PopoutApp` component module.

## Fixes and polish

- Restores correct vertical centering for empty and idle split-panel content after the split header isolation change.
- Keeps split panel focus visuals intact while preventing panel content from visually flattening header controls.
- Removes the Vite HMR `Could not Fast Refresh ("isPopout" export is incompatible)` warning by moving `isPopout()` into a dedicated utility module.

## Notes

- This release includes the split-panel header isolation fix, the follow-up centering correction, and the Popout Fast Refresh cleanup.
- GitHub Actions release packaging is triggered by pushing the `v1.7.21` tag.
