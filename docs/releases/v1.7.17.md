# Sorcerer v1.7.17

Released: 2026-04-20

## Highlights

- Removes the default first-item highlight from context menus so they open neutrally at the mouse position instead of preselecting an action.
- Fixes import-session ordering so external Claude Code and Codex sessions are listed newest-first even when providers report mixed second and millisecond timestamps.
- Tightens Codex resume typing and metadata handling so the current codebase typechecks cleanly before release.

## Fixes and polish

- Keeps arrow-key navigation working in context menus even when no item is initially focused.
- Normalizes release-facing session import behavior across providers by sorting candidates with a shared timestamp conversion.
- Cleans up session creation and import metadata assignments to avoid `null`/`undefined` mismatches in the main process.

## Notes

- This release includes all commits since `v1.7.16`.
- GitHub Actions release packaging is triggered by pushing the `v1.7.17` tag.
