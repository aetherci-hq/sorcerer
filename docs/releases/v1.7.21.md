# Sorcerer v1.7.21

Released: 2026-05-04

## Highlights

- Improves sidebar and popout performance by reducing repeated persistence, timer fanout, hydration work, and remote polling churn.
- Fixes split-panel header rendering so focus styling and right-side controls stay visually isolated from terminal content after creating splits.
- Tightens the release-note process with a required format and source-of-truth files under `docs/releases/`.

## Fixes and polish

- Debounces sidebar layout persistence during drag interactions so resizing does not write state continuously.
- Reduces startup and remote-control polling churn that could make the app do unnecessary background work.
- Trims sidebar project timer fanout and caches briefing configuration lookups to avoid avoidable renderer and main-process work.
- Scopes popout hydration to mounted panels, reducing the amount of panel state restored for windows that are not active.
- Refines sidebar resize behavior for a steadier drag experience.
- Restores correct vertical centering for empty and idle split-panel placeholders after header isolation.
- Removes the Popout Fast Refresh warning in development by moving `isPopout()` into a dedicated utility module.
- Migrates cleanup backlog items into tracked issues and adds release-note templates and guidance.

## Notes

- This release includes all commits since `v1.7.20`.
- The user-visible focus is app responsiveness and split-panel visual stability, with documentation cleanup for release publishing.
- GitHub Actions release packaging is triggered by pushing the `v1.7.21` tag.
