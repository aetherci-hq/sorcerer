# Sorcerer v1.7.15

Released: 2026-04-14

## Highlights

- Added the AetherCI Light theme.
- Improved general session and panel UX, including new-session defaults and workflow polish across the main desktop UI.
- Significantly upgraded the remote control mobile experience with fullscreen session views, sidebar-style status indicators, theme parity, direct terminal typing, and a more usable fallback input flow.

## Fixes and polish

- Smoothed remote-control mobile input handling, including better submit behavior and reduced viewport and keyboard-related jank.
- Brought remote control visuals into parity with the desktop sidebar for active-session badges, theme mapping, and status presentation.
