# Sorcerer v1.7.19

Released: 2026-04-28

## Highlights

- Carries forward the `v1.7.18` feature set: restored panel layouts across restart, independent split layouts in pop-out windows, and hardened Codex session capture, resume, and import behavior.

## Fixes and polish

- Hardens the GitHub Actions macOS release build against transient upstream packaging failures by retrying the mac build step.
- Keeps the existing import-session UX, pane relocation fix, Claude provider badge visibility, and Codex resume/capture refresh improvements from `v1.7.18`.

## Notes

- This release supersedes `v1.7.18`, whose macOS packaging failed due to a transient `dmg-builder` download error in CI.
- GitHub Actions release packaging is triggered by pushing the `v1.7.19` tag.
