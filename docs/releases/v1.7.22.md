# Sorcerer v1.7.22

Released: 2026-05-05

## Highlights

- Fixes a critical Windows shutdown crash where closing Sorcerer could show an Electron "A JavaScript error occurred in the main process" popup.
- Hardens shutdown persistence so database write failures while saving window state, terminal exit state, or scheduled-agent completion are logged instead of escaping as main-process errors.

## Fixes and polish

- Makes window-bounds persistence best-effort during resize, move, maximize, and close handling.
- Contains PTY exit persistence failures during app shutdown so session and agent cleanup cannot interrupt the close sequence.
- Catches Codex live-output and exit-identity persistence failures from PTY callbacks.
- Catches scheduled-agent completion failures from PTY exit handling to avoid unhandled promise rejections.
- Catches final database close failures while still allowing the application to quit.

## Notes

- This is a critical patch release for the close-time main-process crash reported after v1.7.21.
- This release includes all commits since `v1.7.21`.
- GitHub Actions release packaging is triggered by pushing the `v1.7.22` tag.
