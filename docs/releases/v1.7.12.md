# Sorcerer v1.7.12

Released: 2026-04-07

## Highlights

- Introduces provider registry and first-class provider behavior across sessions, missions, dialogs, and orchestration flows.
- Adds provider settings and trust bootstrap support, plus session `started_at` tracking for better startup and history consistency.
- Adds focus mode and resizable sidebar panes to improve dense multi-agent workflows.

## Fixes and polish

- Preserves terminal backgrounds when switching themes.
- Tightens agent row and provider badge alignment in the sidebar.
- Fixes sidebar and viewport context menu clamping, portal measurement, and related menu placement issues.
- Replaces low-value toasts with more contextual feedback.
- Improves activity panel readability and makes it provider-agnostic.
- Defers startup maintenance until after window load for a smoother initial render.
- Avoids scrollback call-stack overflow on large terminal buffers.
- Updates settings dialog keybindings and briefing controls.

## Notes

- This release includes all commits since `v1.7.11`.
- GitHub Actions release packaging is triggered by pushing the `v1.7.12` tag.
